    Our History

    Shangri-La Singapore opened on 23 April 1971 on Orange Grove Road, the very first hotel in what became the Shangri-La Hotels and Resorts group — founded by Malaysian businessman Robert Kuok. Every other Shangri-La property worldwide traces its lineage back to this address.

    The hotel grew in three stages: the Tower Wing (1971), the Garden Wing (1978), and the exclusive Valley Wing (1985). The Garden Wing underwent a S$66 million renovation completed in 2012.

    Set on around 15 acres of landscaped grounds, the hotel is often described as Singapore's original urban resort — a rare amount of greenery this close to Orchard Road.

    Connect (one time only)

    To save changes, this screen needs a GitHub access token. It stays on this device and is never sent anywhere except GitHub.

    1. On GitHub (use the Desktop site), tap your profile photo, then Settings.
    2. Scroll the left menu to Developer settings, then Personal access tokens, then Fine-grained tokens, then Generate new token.
    3. Name it Compass admin. Set expiry to 1 year. Under Repository access choose Only select repositories and pick Concierge-list-2026.
    4. Under Permissions, open Repository permissions, set Contents to Read and write.
    5. Tap Generate token, copy it, and paste it below.
